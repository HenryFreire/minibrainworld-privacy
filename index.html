Política de Privacidad — MiniBrain World

Última actualización: 2025-11-16

Desarrollador: Henry Freire

MiniBrain World (“la aplicación”, “el juego”) es un juego móvil desarrollado por Henry Freire. Esta Política de Privacidad explica cómo se recopila, utiliza y protege la información dentro del juego.

1. Información que recopilamos

MiniBrain World no recopila información personal identificable. Recopilamos solamente datos técnicos necesarios para que el jugador pueda usar el juego correctamente.

1.1 Autenticación de Firebase

Usamos inicio de sesión anónimo de Firebase para generar un ID único de usuario (UID). No recopilamos nombre, correo ni datos personales.

1.2 Datos de progreso

Guardamos únicamente datos como personajes desbloqueados, monedas y progreso del jugador.

1.3 Datos técnicos

Firebase puede recopilar información del dispositivo y reportes de fallos para mejorar la estabilidad del juego.

2. Cómo usamos la información

  • Guardar tu progreso
  • Mantener tus personajes desbloqueados
  • Mejorar el rendimiento
  • Evitar fraude o uso indebido

3. Con quién compartimos tus datos

No compartimos ni vendemos datos a terceros. Los únicos servicios que procesan información son plataformas de Google Firebase.

4. Seguridad

Protegemos tus datos con medidas técnicas como reglas de acceso y conexiones cifradas.

5. Eliminación de datos

Si deseas que eliminemos tus datos, puedes escribir a henryfreire.dev@gmail.com.

6. Datos de menores

MiniBrain World es apto para menores, ya que no recopila datos personales ni permite comunicación entre usuarios.

7. Cambios en esta política

Podemos actualizar esta política y los cambios entrarán en vigor cuando se publiquen aquí.
